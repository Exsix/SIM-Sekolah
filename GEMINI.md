# Project Rules & Guidelines

## Frontend Design & Development
Whenever designing, building, styling, or refactoring frontend interfaces, web components, UI layouts, pages, or visual artifacts:
- **Always activate and follow the `frontend-design` skill**.
- Commit to a distinctive, bold aesthetic direction suited for the context. Avoid generic AI-generated aesthetics (e.g. overused fonts like Inter/Roboto/Arial, generic purple gradients on white, predictable cards/layouts).
- Pay meticulous attention to typography, cohesive color palettes with CSS variables, intentional motion/animations, spatial composition, and visual depth.
